> Эта страница на GitHub — единственное место, откуда стоит скачивать **windows-settings**.
> Если вы нашли «такую же» программу где-либо ещё (Telegram, торренты, левые сайты) — это **фейк** и может содержать что угодно.

> [!WARNING]
>
> ### Программа меняет систему
> **windows-settings** запускается с правами **администратора** и может удалять предустановленные компоненты Windows, отключать системные службы, менять политики реестра и задачи планировщика.
>
> Это нормально, пока вы понимаете, что делаете. Но:
>
> - Некоторые компоненты используются самой Windows (например, **Безопасность Windows / Microsoft.SecHealthUI**, **Параметры**, **проводник**) — после их удаления часть функций ОС перестанет работать
> - Восстановление через `winget` / Microsoft Store работает не для всех пакетов — кое-что вернуть штатно невозможно
> - Отключение телеметрии Windows влияет на службу `DiagTrack` — после этого `Feedback Hub` и часть диагностики работать не будут
> - **Перед массовыми изменениями сделайте точку восстановления системы** или резервную копию диска
>
> Используйте на свой страх и риск.

> [!IMPORTANT]
> Бинарный `windows-settings.exe` в [релизах](https://github.com/EnderMur/windows-settings/releases) собирается **GitHub Actions** прямо из исходного кода этого репозитория. Вы можете в любой момент сверить SHA-256 хэш .exe из релиза с тем, что соберётся локально командой `cargo build --release`.

## ⚙️ Использование

1. Скачайте **`windows-settings.exe`** со [страницы последнего релиза](https://github.com/EnderMur/windows-settings/releases/latest)

2. Зайдите в свойства скачанного файла и поставьте галочку «Разблокировать» (если она есть)

3. Запустите `windows-settings.exe` двойным кликом

4. Согласитесь на запрос UAC (программе нужны права администратора, чтобы работать с системными пакетами, службами и реестром)

5. Выберите слева нужный раздел:
   - <img src="https://cdn-icons-png.flaticon.com/128/553/553384.png" height=12 /> **`Главная`** — состояние системы и приложения
   - <img src="https://cdn-icons-png.flaticon.com/128/3081/3081559.png" height=12 /> **`UWP приложения`** — удаление и восстановление встроенных приложений
   - <img src="https://cdn-icons-png.flaticon.com/128/2099/2099196.png" height=12 /> **`Телеметрия`** — отключение фоновой телеметрии популярного ПО
   - <img src="https://cdn-icons-png.flaticon.com/128/2099/2099058.png" height=12 /> **`Настройки`** (внизу) — уровень логирования

## ℹ️ Описание интерфейса

### <img src="https://cdn-icons-png.flaticon.com/128/553/553384.png" height=14 /> Главная

Открывается при старте. Здесь две карточки:

- **`О системе`** — собирается через `Win32_OperatingSystem` / `Win32_ComputerSystem` / `Win32_Processor` / `Win32_VideoController`:
  - ОС (название + build + разрядность)
  - Имя ПК
  - Пользователь и пометка `(администратор)` / `(без прав администратора)`
  - Процессор
  - Видеокарта (если их несколько — все через запятую)
  - Объём ОЗУ
- **`Приложение`** — версия, ссылка на репозиторий, статус обновления и кнопки:
  - **`Проверить обновления`** — повторная ручная проверка
  - **`Обновить`** — появляется только если на GitHub есть более новая версия. Подменяет `.exe` через стандартный механизм Windows; после обновления нужно перезапустить программу вручную
  - **`Добавить токен`** — появляется только при ошибке `HTTP 403` (см. раздел про GitHub-токен ниже)

Проверка обновлений запускается автоматически при старте программы.

### <img src="https://cdn-icons-png.flaticon.com/128/3081/3081559.png" height=14 /> UWP приложения

Список из **37+ предустановленных** приложений Windows 11 с возможностью удалять и восстанавливать. Список включает Microsoft Store, Калькулятор, Камеру, Карты, Xbox, Cortana, Teams, OneNote, Paint, Записки, Solitaire, Clipchamp и т. д. Статус каждого приложения проверяется автоматически при запуске через `Get-AppxPackage` и обновляется после каждой операции.

Напротив каждого приложения — кнопка:

- <img src="https://cdn-icons-png.flaticon.com/128/1828/1828843.png" height=12 /> **`Удалить`** — приложение установлено, можно убрать
- <img src="https://cdn-icons-png.flaticon.com/128/2961/2961957.png" height=12 /> **`Восстановить`** — приложения нет, можно вернуть

### <img src="https://cdn-icons-png.flaticon.com/128/2099/2099196.png" height=14 /> Телеметрия

Отключение фоновой телеметрии для шести категорий ПО. Изменения применяются через **политики реестра**, **отключение служб** (`Set-Service -StartupType Disabled`) и **отключение задач планировщика**:

- **Microsoft Office** — задачи `OfficeTelemetryAgent*` + политики `EnableLogging` / `EnableUpload` / `ClientTelemetry`
- **Mozilla Firefox** — `DisableTelemetry`, `DisableFirefoxStudies`, `DisableDefaultBrowserAgent`
- **Google Chrome** — `MetricsReportingEnabled = 0` + задачи `GoogleUpdateTask*`
- **NVIDIA** — служба `NvTelemetryContainer` + задачи `NvTmRep*` / `NvTmMon*` / `NvNodeLauncher*`
- **Visual Studio (VSCEIP)** — `SQM\OptIn = 0` и `Feedback\Disable*` для VS 2015–2022
- **Windows 11** — службы `DiagTrack` и `dmwappushservice` + политика `AllowTelemetry = 0`

Статус каждой категории определяется автоматически при запуске; кнопка показывает противоположное действие (**`Отключить`** / **`Включить`**) — все изменения **обратимы** в один клик.

### <img src="https://cdn-icons-png.flaticon.com/128/2099/2099058.png" height=14 /> Настройки

- **`Сбор логов`** — приложение пишет лог в `%APPDATA%\WindowsSettings\logs\run_YYYYMMDD_HHMMSS.log` (новый файл при каждом запуске). Уровень детализации:
  - <ins>**`Обычный`**</ins> — события и результаты операций
  - **`Debug`** — дополнительно полные PowerShell-скрипты и их вывод (для отладки/баг-репортов)

## 🔑 GitHub-токен (опционально)

Анонимный API GitHub ограничен **60 запросами в час с одного IP**. Если приложение часто проверяет обновления (запуски, перезапуски), может вылететь ошибка `HTTP 403`. В этом случае:

1. На карточке **`Приложение`** появится кнопка **`Добавить токен`**
2. Создайте Personal Access Token: `github.com` → Settings → Developer settings → Personal access tokens → Tokens (classic). Для публичного репозитория достаточно scope `public_repo`
3. Вставьте токен в открывшееся окно и нажмите **`Сохранить`**

Токен сохраняется в `%APPDATA%\WindowsSettings\config.json` и подставляется во все последующие запросы к API. Лимит поднимается до **5000 запросов в час**. Удалить токен можно той же кнопкой `Удалить` в окне ввода.

## ☑️ Распространённые вопросы и проблемы

### Кнопка «Удалить» нажата, но приложение не удалилось

- Откройте **`Настройки`** → **`Сбор логов`** → переключите на **`Debug`**
- Повторите удаление
- Откройте текущий лог-файл (путь показан в настройках) и посмотрите, что вернул PowerShell в строке `PS<`
- Чаще всего причина одна из:
  - Приложение помечено как «system» и Windows не даёт его удалить для текущего пользователя без `-AllUsers`
  - В системе включена политика, блокирующая `Remove-AppxPackage`

### Кнопка «Восстановить» работает не для всех приложений

Это ожидаемо. Программа пытается восстановить приложение по трём сценариям подряд:

1. **Перерегистрация** из `Get-AppxPackage -AllUsers` (если файлы пакета всё ещё лежат в `C:\Program Files\WindowsApps\…`)
2. **`winget install`** — если winget установлен и в его источнике есть пакет
3. **Открытие Microsoft Store** на странице приложения для ручной установки

Если пакет уже полностью удалён с диска и его нет в winget, единственный путь — установить из Microsoft Store вручную.

### Кнопка «Отключить» / «Включить» телеметрию ничего не меняет

- Включите **`Debug`** в настройках и повторите действие
- Откройте лог — там видно, что вернул PowerShell на каждом этапе (политика реестра, служба, задачи планировщика)
- Самая частая причина — отсутствие прав администратора (особенно для веток `HKLM` и служб); проверьте, что согласились на запрос UAC при запуске

### Программа не запускается / закрывается сразу

- Убедитесь, что вы согласились на запрос UAC
- Антивирус мог положить `.exe` в карантин — добавьте папку с программой в исключения
- Откройте `%APPDATA%\WindowsSettings\logs\` и посмотрите последний лог-файл — обычно там видно причину

### «Доступна версия X», но «Обновить» не работает

- Скорее всего нет интернета или GitHub временно недоступен. Подробности — в логе при включённом **`Debug`**
- Если в статусе обновлений видно `HTTP 403` — это лимит анонимных запросов GitHub, добавьте токен (см. раздел выше)

### Что-то сломалось после удаления приложения / отключения телеметрии

- UWP-приложение — попробуйте кнопку «Восстановить»
- Телеметрию — нажмите «Включить» на той же карточке, всё вернётся
- Если кнопки не помогли — откатите систему через точку восстановления Windows
- В крайнем случае — `sfc /scannow` и `DISM /Online /Cleanup-Image /RestoreHealth` в терминале от администратора

### Не нашли свою проблему

- Создайте [Issue](https://github.com/EnderMur/windows-settings/issues), желательно с приложенным лог-файлом из `%APPDATA%\WindowsSettings\logs\` (с включённым Debug)
