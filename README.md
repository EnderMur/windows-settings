## Установка и запуск

1. Скачайте последнюю версию из раздела **Releases**.
2. При необходимости разблокируйте файл в свойствах Windows.
3. Запустите `.exe`.
4. Подтвердите запрос UAC - программе нужны права администратора.
5. Управляйте системой через интерфейс приложения.

## Ограничения API

Некоторые функции могут иметь лимиты запросов. При их превышении возможны ошибки или временная блокировка. Для увеличения лимитов может использоваться персональный токен доступа.

## Частые вопросы

**Приложение не удаляет компонент.**  
Некоторые системные приложения защищены Windows и требуют расширенных прав или отдельного сценария удаления.

**Восстановление работает не всегда.**  
Если компонент полностью удалён, восстановление возможно только через Microsoft Store или повторную установку системы.

**Изменения не применяются.**  
Проверьте, что программа запущена с правами администратора.

**Программа не запускается.**  
Проверьте антивирус, блокировку SmartScreen и права на запуск.
