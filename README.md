> [!CAUTION]
>
> ### Единственный источник
>
> Загружайте программу только из официального репозитория или страницы релизов.
> Любые копии из Telegram, сторонних сайтов, форумов или торрентов могут быть изменены и потенциально опасны.

> [!WARNING]
>
> ### Программа изменяет систему
>
> Это приложение работает с правами **администратора** и может вносить изменения в компоненты Windows, включая:
>
> * удаление предустановленных приложений
> * отключение системных служб
> * изменение параметров реестра и политик
> * управление задачами планировщика
>
> Некоторые изменения могут быть частично или полностью необратимыми.
>
> ⚠️ Перед использованием рекомендуется создать **точку восстановления системы** или резервную копию.
>
> Используйте на свой страх и риск.

> [!IMPORTANT]
>
> ### Проверяемая сборка
>
> Исполняемый файл в разделе релизов собирается автоматически из исходного кода через CI/CD.
> При необходимости вы можете самостоятельно собрать проект и сравнить контрольные суммы с опубликованной версией.

## ⚙️ Использование

1. Скачайте последнюю версию программы из раздела **Releases**
2. При необходимости разблокируйте файл в свойствах Windows
3. Запустите `.exe` от имени пользователя
4. Подтвердите запрос UAC (требуются права администратора)
5. Используйте интерфейс для управления системой

## 🧭 Основные разделы

### 🏠 Главная

Панель состояния системы и приложения:

* информация об ОС, железе и пользователе
* статус прав администратора
* сведения о версии программы и обновлениях
* управление обновлением приложения

---

### 📦 Приложения

Раздел управления встроенными компонентами Windows:

* список предустановленных UWP-приложений
* удаление ненужных компонентов
* восстановление системных приложений при необходимости
* автоматическая проверка текущего состояния пакетов

---

### 🔒 Телеметрия

Раздел управления диагностикой и сбором данных:

* отключение телеметрии ОС и сторонних программ
* управление службами, задачами и политиками
* поддержка популярных приложений (браузеры, офисные пакеты, драйверы и т.д.)
* возможность полного восстановления исходных настроек

---

### 🧹 Очистка

Раздел очистки дискового пространства:

* вычисление размера временных и системных файлов
* безопасное удаление мусора (кеш, корзина, WinSxS, Windows.old)
* подробный отчёт по каждой категории перед очисткой
* предупреждение об опасных операциях

---

### 🧠 ОЗУ

Раздел управления оперативной памятью:

* мониторинг используемой, доступной, резервной и изменённой памяти
* наглядный график распределения ОЗУ
* четыре режима очистки: PurgeStandby, EmptyWorkingSets, всё и настройка объёма
* принудительная очистка через оптимизацию списка страниц

---

### ⚙️ Службы

Раздел управления системными службами:

* список ключевых служб Windows с описанием назначения
* быстрое включение/отключение служб
* управление типом запуска (автоматический, вручную, отключена)
* контроль состояния после изменений

---

### ⚙️ Настройки

Общие параметры приложения:

* уровень логирования (обычный / расширенный)
* отображение скрытых функций
* сохранение конфигурации пользователя
* диагностика операций и вывод отладочной информации

## ❗ Частые вопросы

### Приложение не удаляет компонент

Некоторые системные приложения защищены Windows и требуют расширенных прав или отдельного сценария удаления.

### Восстановление работает не всегда

Если компонент был полностью удалён из системы, восстановление возможно только через Microsoft Store или повторную установку системы.

### Изменения не применяются

Проверьте, что программа запущена с правами администратора.

### Программа не запускается

Проверьте антивирус, блокировку SmartScreen и наличие прав запуска.
